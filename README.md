# 🗃️ Adatbázisrendszerek 2 – Gyakorlati Feladatok

Ez a repository az **Adatbázisrendszerek 2** egyetemi tárgyhoz kapcsolódó gyakorlati feladatokat tartalmazza. A kurzus során **JDBC** és **PL/SQL** alapú adatbáziskezelő rendszerekkel ismerkedtünk meg, valamint két összetettebb beadandót is készítettünk valósághű szcenáriók alapján.

## 📦 Féléves beadandók

### 📌 Cég adatbáziskezelő rendszer (JDBC & PL/SQL)

Mindkét beadandó célja egy olyan adatbáziskezelő rendszer megvalósítása volt, amely egy lisztes tasakokat gyártó és nyomtató cég működését támogatja.

#### ✅ Főbb funkciók:
- Rendelések nyilvántartása
- Megrendelők adatainak kezelése
- Papírnyomtatás és tasakgyártás állapotának követése

#### 🛠️ Két megvalósítás:
- **JDBC projekt**: Java nyelven készült, adatbázis kapcsolattal
- **PL/SQL projekt**: Oracle környezetben, PL/SQL nyelven
- Mindkettőhöz részletes dokumentáció tartozik

## 🧪 Egyéb gyakorlati feladatok

- JDBC kapcsolatok használatának elsajátítása
- PL/SQL nyelv alapjainak megismerése
- Triggerekkel, tárolt eljárásokkal és függvényekkel való munka

## ⚙️ Követelmények

- JDBC projekt: Java JDK, JDBC driver, RDBMS (pl. MySQL vagy Oracle)
- PL/SQL projekt: Oracle SQL Developer vagy más kompatibilis környezet
